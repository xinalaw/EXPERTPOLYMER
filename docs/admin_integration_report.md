# Отчёт об интеграции frontend и backend

## Исходное состояние

В проекте одновременно существовали рабочее Vue-приложение и отдельные
статические HTML-макеты админ-панели в `backend/app/static/prototypes`.
Макеты содержали только демонстрационные данные и не обращались к API.
Backend уже предоставлял управление ролями, историю и audit logs, но не имел
сводного dashboard и административных списков фоновых задач и инвайтов.

## Что реализовано

- Единая Vue-админ-панель, доступная администраторам из основного меню.
- Разделы: обзор, пользователи, история анализов, Celery-задачи, инвайты,
  журнал действий.
- Управление ролями и назначение директора исследователю.
- Поиск пользователей на клиенте.
- Фильтры истории по пользователю и дате.
- Фильтр задач по статусу.
- Фильтры audit log по действию и дате.
- Отображение актуального состояния инвайта с учётом срока действия.

## Добавленные backend API

Все маршруты требуют JWT пользователя с ролью `admin`.

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/admin/dashboard` | Агрегированная статистика системы |
| GET | `/api/admin/tasks` | Список и фильтрация фоновых задач |
| GET | `/api/admin/invites` | Список директорских инвайтов |

Существующие `/api/users`, `/api/history` и `/api/logs` переиспользованы без
создания дублирующих admin-маршрутов.

## Очистка

- Удалены статические HTML-макеты админ-панели и их CSS: их заменил рабочий
  Vue-интерфейс.
- Удалена документация и исходники старого Express + PostgreSQL frontend API.
- Из `package.json` удалены неиспользуемые `express`, `pg`, `cors`, `dotenv` и
  ссылка на отсутствующий `server.js`.
- Удалён неиспользуемый WebSocket endpoint без авторизации. Отслеживание задач
  остаётся через защищённый HTTP endpoint.
- Удалены связанные `VITE_WS_URL`, клиентский helper и Python-зависимость.
- Две копии FastAPI-зависимости `get_db` заменены одной реализацией в
  `app/database/dependencies.py`.
- Удалены неиспользуемые импорты Celery и два лишних access helper.
- Исправлен ошибочный fallback `/history` во frontend на `/api/history`.
- Pydantic-схемы переведены с устаревшего `class Config` на `ConfigDict`.
- Production npm audit приведён к нулю известных уязвимостей.

## Совмещение с новым frontend

Интерфейс основан на новой версии `origin/main`: TypeScript, Vue Router,
единое состояние авторизации, новые страницы и компоненты анализа сохранены.
Админ-панель подключена к общей сессии и маршруту `/#/admin`, доступному только
пользователям с ролью `admin`. Административные API backend сохранены.

Compose поднимает весь стек вместе с frontend; Vite проксирует `/api` и
`/static` на `http://backend:8000`. Быстрый вариант без torch запускается через
`./scripts/docker-up.sh --mock`; основной `docker compose up -d --build --wait`
сохраняет полный ML-режим. Инструкция создания первого администратора и
сохранения данных находится в [корневом README](../README.md).
