ШАГ 1: ОТРЕДАКТИРУЙТЕ .env
┌────────────────────────────────────────────────────────────────────────────┐
│ Откройте файл .env и заполните параметры вашей PostgreSQL:               │
│                                                                            │
│ DB_HOST=localhost                                                          │
│ DB_PORT=5432                                                               │
│ DB_NAME=expert_polymer         ← имя вашей БД                            │
│ DB_USER=postgres               ← пользователь БД                          │
│ DB_PASSWORD=ВАШ_ПАРОЛЬ        ← пароль к PostgreSQL ⚠️  │
│ PORT=3000                                                                  │
└────────────────────────────────────────────────────────────────────────────┘

ШАГ 2: СОЗДАЙТЕ ТАБЛИЦУ В PostgreSQL
┌────────────────────────────────────────────────────────────────────────────┐
│ Используя расширение PostgreSQL в VS Code:                                │
│                                                                            │
│ 1. Откройте расширение PostgreSQL (левая панель)                         │
│ 2. Найдите вашу БД (expert_polymer)                                      │
│ 3. Нажмите правой кнопкой → "New Query"                                 │
│ 4. Скопируйте содержимое файла query.sql                                 │
│ 5. Выполните SQL (Ctrl + Shift + E)                                      │
│                                                                            │
│ Или используйте команду:                                                  │
│ psql -U postgres -d expert_polymer < query.sql                           │
└────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📡 ОСНОВНЫЕ API ENDPOINTS                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

1️⃣  POST /api/register - Регистрация нового пользователя
    Запрос:
    {
      "firstName": "Иван",
      "lastName": "Иванов",
      "email": "ivan@example.com",
      "password": "password123",
      "organization": "Company"
    }

2️⃣  POST /api/login - Вход в систему
    Запрос:
    {
      "email": "ivan@example.com",
      "password": "password123",
      "rememberMe": true
    }

3️⃣  GET /api/user/:id - Получить информацию о пользователе
    Пример: /api/user/1

4️⃣  POST /api/logout - Выход из системы

Подробное описание см. в файле AUTH_SETUP.md

Проблема: "Database connection error"
Решение:
  □ Проверьте что PostgreSQL запущен
  □ Проверьте параметры в .env
  □ Убедитесь в правильности пароля
  → Полная диагностика в TESTING.md

Проблема: "Table users not found"
Решение:
  □ Выполните SQL из query.sql
  □ Проверьте имя БД в .env
  □ Убедитесь что выполнили запрос в нужной БД
  → Полная диагностика в TESTING.md

Проблема: "Cannot POST /api/register"
Решение:
  □ Убедитесь что сервер запущен (npm run api)
  □ Проверьте консоль сервера на ошибки
  □ Убедитесь что сервер на порту 3000
  → Полная диагностика в TESTING.md

Проблема: "CORS error" или ошибки сети
Решение:
  □ Убедитесь что оба - сервер и фронт запущены
  □ Проверьте что фронт обращается к http://localhost:3000
  □ Проверьте консоль браузера (F12 → Console)
  → Полная диагностика в TESTING.md
