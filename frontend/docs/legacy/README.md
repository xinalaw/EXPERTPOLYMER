# Устаревшая документация

Файлы в этой папке описывают **первую версию** фронтенда, когда он ходил
в собственный Express-сервер (`server.js`) и напрямую в PostgreSQL:

- `00_START_HERE.txt`, `QUICKSTART.md`, `AUTH_SETUP.md`,
  `IMPLEMENTATION_SUMMARY.md`, `TESTING.md`, `INDEX.md` — инструкции по
  настройке того сервера;
- `server.js.old` — сам Express-сервер;
- `query.sql` — схема таблицы пользователей для него.

После объединения проектов фронтенд работает с FastAPI-бэкендом
(`backend/`): авторизация, анализ изображений и история — всё через
`/api/*`, см. `frontend/src/api/`. Собственный Node-сервер больше не нужен
и не запускается.

Файлы оставлены как справка по истории проекта.
